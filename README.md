# carros: Watch pages for the car search (Nov 18, 2026)

Six small pages in Spanish, one per car, built to open on an Apple Watch from a Messages link.
Published with GitHub Pages from the `main` branch: https://marco-sahagun.github.io/carros/

- `car-1.html` … `car-6.html`: one car each. Photo pinned at the top, tap the left or right half for more photos, details below.
- `index.html`: the six cars as one list, for sending a single link instead of six.
- `img/`: listing photos (480 px JPEG) and the link-preview pictures (`prev-N.jpg`, `cover.jpg`).

Snapshot of Facebook Marketplace listings checked Nov 18, 2026; prices and availability can change.
The pages are static files: edit the HTML directly, or regenerate them from the session that built them.
